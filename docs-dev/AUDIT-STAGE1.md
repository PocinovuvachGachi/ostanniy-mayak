Надалі #18 має окремо перевірити, чи гравець бачить причину зупинки й може відновити виробництво.

## Пропозиція порядку (на погодження)
1. Жарина → берег → паливо → уламки. Дати гравцеві зрозуміти ресурсний цикл.
2. Майстерня як зрозуміла мета для вудки й весла (зберегти поточну залежність як найменшу зміну) або рання проста вудка поза майстернею, якщо автор хоче буквального STAGE1. Не змінювати без рішення.
3. Риболовля → краб → спорядження → чайки; зв'язати чайок з реальною дією сушіння або змінити сцену. Зиновій → їжа → пацюки → сліди → утопленик.
4. Горпина → Оглядова → частини броду → попередження про Млу → облога → завершення броду → Причал. Розвести механічні відкриття та сюжетні сцени.
5. Туторіали в момент першого використання (#45); не додавати нових вкладок завчасно.
