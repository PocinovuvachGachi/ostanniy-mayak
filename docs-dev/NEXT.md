  до анімації. Числа пацюків не міняли.

  Герой будується тим самим конструктором: видно броню, зброю, арбалет/пращу/пістоль, оберіг, ліхтар.
- Поступовість: між відкриттями щонайменше 45 с гри (`calm`/`novMark`); креслення й рецепти — по одному.
