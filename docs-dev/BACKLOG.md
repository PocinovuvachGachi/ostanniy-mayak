# Беклог

Ідеї й задачі живуть у GitHub Issues: https://github.com/PocinovuvachGachi/ostanniy-mayak/issues

- Мітки: «ідея», «баг»; постулати — «дослідження», «поступовість», «баланс», «бій», «графіка», «наратив»;
  «інструменти» — засоби перевірки; «зараз» — беремо найближчим часом; «обговорити» — спершу з автором.
- Переглянути з сесії: `gh api "repos/PocinovuvachGachi/ostanniy-mayak/issues?labels=ідея&state=open" --jq '.[]|"#\(.number) \(.title)"'`
  (GraphQL у сесіях недоступний, тож лише REST: `gh api repos/...`).
- Нова ідея — нова issue з мітками постулатів, яким вона служить. Зроблене — коміт «закриває #N».

## Ревізор (ChatGPT)
Автор підключив ChatGPT як ревізора: він перевіряє гру й документи, шукає помилки й пропонує ідеї.
- **Канал — лише issues з міткою «ревізія»** (плюс «баг» чи «ідея» і мітки постулатів). Код ревізор не пушить у `main`;
  правку коду — через pull request або фрагмент в issue.
- **Перед пропозицією** прочитати `CLAUDE.md`, `docs-dev/PRINCIPLES.md`, `DECISIONS.md`, `NEXT.md`, щоб не пропонувати
  вже погоджене чи відкинуте.
- **Як оформлювати баг:** що зробив → що сталося → що мало статися; версія артефакту; за можливості збереження
  (експорт з панелі `?debug`) або кроки з налагодження.
- **Що найкорисніше:** баги з відтворенням; суперечності в текстах і сюжеті; спойлери; місця, де текст світу
  пояснює механіку (постулат «Наратив», #45); баланс і темп на свіже око.
- **Як працює Claude:** на початку блоку переглядає нові «ревізії»
  (`gh api "repos/PocinovuvachGachi/ostanniy-mayak/issues?labels=ревізія&state=open" --jq '.[]|"#\(.number) \(.title)"'`).
  Пропозиції — поради, не завдання: звіряє з постулатами й рішеннями; суперечне — коментар з посиланням на рішення;
  корисне — пропонує автору. Ідеї в роботу — лише після «так» автора; явні баги з відтворенням можна правити одразу.
