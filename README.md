# Останній Маяк

Медитативна піксельна гра про хранителя згаслого маяка: відбудова, шхери, туман і тактичні сутички.

**Грати:** https://pocinovuvachgachi.github.io/ostanniy-mayak/

На телефоні відкрий адресу й обери «Додати на головний екран», щоб гра стала застосунком з іконкою та працювала без інтернету. Збереження лишається у твоєму браузері.

## Як влаштовано

- `src/head.html`, `src/style.css`, `src/body.html` — оболонка сторінки.
- `src/js/*.js` — код гри, склеюється за порядком у назві:
  - `00–02` — піксельна графіка і сцени;
  - `10–14` — тексти, дані, локації, стан, помічники;
  - `20–22` — бої, логіка локацій, головоломки;
  - `30` — дії гравця, `40–48` — відмальовка, сцени, міні-ігри, Літопис;
  - `49` — звук, `90` — збереження й головний цикл, `95` — панель налагодження.
- `src/sw.js` — офлайн-режим.
- `tests/` — автоматичні перевірки.
- `docs-dev/` — як влаштовано (`ARCHITECTURE.md`), що погоджено (`DECISIONS.md`), що далі (`BACKLOG.md`).
- `assets/` — іконки.
- `build.py` — збирає все в один файл.

## Збірка

```
python3 build.py
```

- `docs/` — готовий сайт для GitHub Pages (Settings → Pages → гілка `main`, папка `/docs`).
- `dist/game.html` — та сама гра однією сторінкою без обгортки.

## Перевірки

```
node tests/run.js
```

Збирає гру, проганяє сценарії логіки (детерміновано) і перевірки в браузері. Те саме автоматично
запускається на GitHub після кожного пушу (вкладка Actions).

## Знайшов баг чи маєш ідею?

Створи issue: вкладка **Issues → New issue → Баг / Ідея**. Скріншот можна просто перетягнути.

Панель налагодження: додай `?debug` до адреси гри (наприклад,
`https://pocinovuvachgachi.github.io/ostanniy-mayak/?debug`). Там можна швидко отримати ресурси,
відкрити вкладки, запустити міні-гру чи набіг, перемотати час, а також скопіювати збереження,
щоб додати його до звіту про баг.
