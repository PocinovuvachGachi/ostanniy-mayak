# Останній Маяк — інструкції для Codex

Codex продовжує роль ChatGPT як другого розробника поряд із Claude. Автор ухвалює рішення. Мова гри, документації, комітів і відповідей автору — українська.

## Перед кожним завданням
Прочитай CLAUDE.md (спільні правила), docs-dev/PRINCIPLES.md, DECISIONS.md, NEXT.md, TEAM.md, ARCHITECTURE.md, ROADMAP.md та відповідний STAGE*.md у docs-dev/. Перевір актуальні issues, PR, main і CI; не вважай старі нотатки доказом злиття. Стартовий контекст — docs-dev/CODEX-HANDOFF.md. Не дублюй наявні документи.

## Робочий процес
- Бери погоджену issue, мітка gpt, коментар «Беру. Зачеплю: …». Не перетинайся з Claude. Гілки gpt/… від актуального main; PR замість прямого пушу в main.
- Змінюй src/, а не зібраний HTML вручну. python3 build.py; node tests/run.js. Для балансу/відкриттів/боїв також node tests/run.js --sim і --fights. Якщо повний набір недоступний, --logic і CI; чесно вкажи обмеження. Перевір мобільну ширину 390 px, консоль, анімації та старі збереження. Не обходь реальні умови в тестах.
- У PR опиши результат, перевірки, ризики, issue. Онови NEXT.md; нові погоджені рішення — DECISIONS.md, архітектуру — ARCHITECTURE.md. Конфлікти в docs/ вирішуй повторною збіркою.
- Автор раніше дозволив додавати погоджені зміни ChatGPT без очікування Claude; не поширюй цей дозвіл на непогоджені концепції, конфліктні PR або неперевірені зміни. Дотримуйся TEAM.md і перевіряй CI перед злиттям.
- Не підміняй результати симулятора ручним тестуванням. Публікація артефакту Claude лишається за Claude; GitHub Pages оновлюється з main.

## Незмінні орієнтири
Медитативність, відсутність втрат за відсутності гравця, поступове відкриття без спойлерів, наратив окремо від навчання, зміст замість штучного здорожчання та таймерів, піксель-арт кодом. Ціль — 30–40 год активної неквапливої гри для актів I–II; ендгейм ще не погоджений. Не перепитуй про вже погоджені рішення.
