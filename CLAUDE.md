# Останній Маяк — нотатки для розробки

Почни з цього файлу, потім:
- `docs-dev/PRINCIPLES.md` — **постулати розробки від автора: головні орієнтири, звіряй з ними кожну зміну**;
- `docs-dev/ARCHITECTURE.md` — карта модулів і ключові механізми;
- `docs-dev/DECISIONS.md` — що вже погоджено з автором (не перепитувати);
- `docs-dev/BACKLOG.md` — що далі; баги — у GitHub Issues (`gh issue list`).

## Правила
- Мова гри, комітів і спілкування з автором — українська.
- Код гри — модулі в `src/js/`, склеюються за алфавітом у `build.py`.
- Після змін: `node tests/run.js` (збирає гру й проганяє всі перевірки), потім комміть разом `src/`, `docs/`, `tests/`.
- Пуш: `git -c push.negotiate=true push`.
- `docs/` публікується через GitHub Pages; `dist/` у git не потрапляє.
- Публікація на claude.ai (артефакт https://claude.ai/artifact/1f8nduYDt8JYFECHaMqPjZ) — з `dist/game.html`.
- Нове погоджене рішення — дописати в `docs-dev/DECISIONS.md`; нова ідея на потім — у `BACKLOG.md`;
  новий модуль чи механізм — в `ARCHITECTURE.md`.

## Принципи гри (коротко; детально — DECISIONS.md)
- медитативність і гра на фоні; жодних втрат, поки гравця немає;
- поступове відкриття механік, без спойлерів (жодних «N з M», імен майбутніх ворогів/предметів);
- текст голосом світу, механіка — у підказках «i»;
- діалоги «Відкрилося: …»; предмети — коротко в картці, повністю в підказці;
- піксель-арт генерується кодом (палітра `PAL` у `00-art-core.js`).

## Тести
- `node tests/run.js` — усе; `--logic` — лише логіка (секунди); `--browser` — лише браузер.
- Логічні тести детерміновані (`SEED`, фальшивий годинник). Новий сценарій — файл у `tests/logic/`,
  що друкує `FAIL …` і наприкінці `fails N`.
- Браузерні перевірки: без помилок у консолі, без горизонтальної прокрутки на 390 px на всіх вкладках.
- Для ручної перевірки: відкрий гру з `?debug` (або `#debug` в артефакті) — панель налагодження
  дає ресурси, вкладки, міні-ігри, набіг, перемотку часу й експорт/імпорт збереження.
- Якщо автор надіслав збереження з issue — встав його в поле панелі налагодження.
